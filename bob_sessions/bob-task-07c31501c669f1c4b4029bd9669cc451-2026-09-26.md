### 2. What Was Inspected

**Natural-language query flow:** [`runAnalysis()`](src/App.jsx:2062) fires on button click or Enter. It calls `/api/ai/analyze` with the question plus the full `dataContext`. On success it applies `resolveAIResult()`. On failure it falls back to `getLocalResolution()`. Both paths correctly set `scenarioTariff`, `appliedScenario`, `analyzedQuestion`, and `scenarioHistory`.

**Extraction functions:**
- [`extractPercentage()`](src/App.jsx:103) — matches all `N%` occurrences and uses the last one (correct for "from 10% to 25%").
- [`extractYear()`](src/App.jsx:127) — regex `\b20\d{2}\b`, defaults to current year.
- [`extractProduct()`](src/App.jsx:148) — keyword alias table covers all five products.
- [`extractCountry()`](src/App.jsx:267) / [`extractExplicitDestinationCountry()`](src/App.jsx:244) — pattern-based, falls back to `"India"`.
- [`extractSourceCountry()`](src/App.jsx:323) — only resolves when a `from <country>` phrase is present, validated against the dataset.

**React Flow graph:** [`createGraphData()`](src/App.jsx:770) generates 7 nodes and 6 edges. The `useEffect` that calls it is keyed on `graphKey` (a string encoding product, source, destination, tariffs, downstream). Nodes are `draggable`, edges are `animated`. `filteredNodes`/`filteredEdges` apply search dimming, filter hiding, and path opacity.

**Node clicking/dragging/details:** `onNodeClick` sets `selectedNodeId`. `NodeDetailsContent` renders data, relationships, reasoning path, explanation, optional IBM AI insight, and supporting source. `highlightPath` toggle dims non-path nodes and edges.

**Evidence, reasoning path, AI analysis:** `evidence[]` array has 3 records derived from `analysis`. `getReasoningPath()` slices `reasoningOrder` up to the selected node. `Classification` component separates FACT / INFERENCE / POSSIBILITY.

**Trade Data / Timeline / Scenario History / Methodology:** All four tabs render correctly. Scenario History is populated by both `applyResolvedAnalysis()` and the catch block. `resetScenario()` appends a RESET entry.

**What-If Simulator:** Slider range 0–50%, `applyScenario()` commits `appliedScenario`, `resetScenario()` restores `analysis.currentTariff`. Both update history.

**Fallback behaviour:** The `useEffect` health-check fetches `/api/health`; on failure (including network error) it sets `aiStatus = "FALLBACK"`. The `runAnalysis` catch block also sets `"FALLBACK"` and continues with local extraction. The UI shows an amber banner when `aiError` is set.
